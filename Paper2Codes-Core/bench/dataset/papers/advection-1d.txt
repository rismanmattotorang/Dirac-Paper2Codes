First-Order Upwind Scheme for 1D Linear Advection

Abstract. The 1D linear advection equation du/dt + c du/dx = 0 is solved with
the explicit first-order upwind finite-difference scheme.

1. Method (Algorithm 1). For wave speed c > 0, spacing dx, step dt:
  Equation (1): u_i^{n+1} = u_i^n - (c dt / dx) (u_i^n - u_{i-1}^n)

2. Stability (CFL).
  Equation (2): c dt / dx <= 1

3. Implementation notes. Advance a periodic initial profile by N steps; assert
the CFL condition. Validate that a constant profile is preserved exactly.
